Contribution Guidelines
=======================

Thanks for your interest in improving the pyOpTools workbench.

The full contributor guide lives in the repository root:

* `CONTRIBUTING.md <https://github.com/cihologramas/freecad-pyoptools/blob/master/CONTRIBUTING.md>`_
  — development setup, running the test suite, and the pull-request workflow.
* `AGENTS.md <https://github.com/cihologramas/freecad-pyoptools/blob/master/AGENTS.md>`_
  — project-specific decisions and pitfalls for AI coding assistants.

In short
--------

#. Clone the repository into FreeCAD's ``Mod`` directory and select the
   **pyOpTools** workbench.
#. Run the test suite with ``tests/run.sh all`` (headless) and
   ``tests/run.sh gui`` (needs a display) before opening a pull request.
#. Keep one logical change per commit and describe the *why* in the pull
   request.
#. Contributions are licensed under the GPL-3.0-or-later.
